# Color Betting Game

Simple Node.js/Express demo where players bet on a color and an admin chooses the winning color.

## Setup

```bash
npm install
```

## Usage

Run the server:

```bash
npm start
```

Player interface: `http://localhost:3000/`

Admin panel: `http://localhost:3000/admin.html`

Admin can set the winning color and resolve bets; players place bets by selecting a color and entering their name.
